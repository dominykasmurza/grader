# Examples

- `AnswerKey.xlsx` - answer key template
- `grader.png` - logo for top right section
- `scanned_sheets` - real hand-filled and scanned sheets for validation
- `bulk_detected` - grader output after processing `scanned_sheets`
- `sticker.ezpx` - example sticker for resetting the answer fields, from GoLabel software. Validated to work with Godex G500 label printer, 30 mm x 20 mm stickers with rounded corners
- `qr_sheets.csv` - input .csv file for generating QR-encoded answer sheets
- `qr_answer_sheets_example.pdf` - example output of QR-encoded answer sheets
